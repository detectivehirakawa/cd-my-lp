# 調査日報作成フォーム（nippo）

公開URL: https://lp.exeresearch.jp/nippo/

- `index.html` … 日報入力フォーム本体（単一ファイル、サーバー不要）
- `gas.gs` … LINEグループ自動送信＋Googleマップのリンク変換用の Google Apps Script（下記手順で貼り付ける）

## 使い方（調査員向け）

スマホ前提の画面です。上から順に埋めると、下の「出力プレビュー」に日報テキストができます。

- **移動手段で経費欄が変わります。** 車・バイクを選ぶとガソリン代・アイドリング・高速代、
  電車を選ぶと駅名〜駅名の運賃欄が出ます。両方使った日は「＋ 車の経費も入れる」「＋ 電車代も入れる」で足せます。
- **高速代はIC名で自動計算します。** 入口IC・出口ICと金額を一度入れると、その区間の料金をこの端末が覚えます。
  次回から同じ区間は金額が自動で入り、復路（逆区間）にも同額が入ります。
  **金額は移動手段に連動**し、車なら普通車ETC、バイクなら二輪ETCの登録額を使います。
  二輪の確定額が未登録の区間は普通車の0.8倍を**概算**として入れ、オレンジの「概算・要確認」が付きます。
  正しい額を上書きすれば、その区間の二輪料金として覚え直します。「調べる」ボタンで料金検索を開けます。
- **電車代も同じ仕組みです。** 乗車駅・降車駅と金額を一度入れれば次回から自動で入ります。
- **調査詳細は自由入力**です。書いた内容がそのまま出力されます。下のボタンは定型文をカーソル位置に差し込む補助で、使わなくても構いません。
- **「LINEグループに送信」を押すと、端末に保存したうえでグループへ直接投稿されます。** 送信先を選ぶ操作は不要です。
  「保存」は端末内に残すだけで送信しません。
- 覚えた区間の料金はブラウザに保存されるため、端末を変えると引き継がれません。
  「保存一覧」のJSON書き出しに料金メモも含まれるので、別端末ではそれを読み込んでください。

## LINEグループ自動送信のセットアップ（管理者が1回だけ行う）

「LINEグループに送信」ボタンで日報を公式LINEから特定のLINEグループへ投稿する仕組みです。
公開ページに秘密のトークンを置けないため、Google Apps Script（GAS）を中継に使います。

### 1. LINE公式アカウント側（Messaging API）

1. https://developers.line.biz/console/ にログイン → プロバイダーを作成（既にあればそれを使う）
   → 「Messaging API」チャネルを作成（既存の公式アカウントを使う場合は
   LINE Official Account Manager → 設定 → Messaging API → 「Messaging APIを利用する」）。
2. チャネルの「Messaging API設定」タブ → 一番下の **チャネルアクセストークン（長期）** を「発行」してコピー。
3. 同じタブの「LINE公式アカウント機能」で
   - **グループトーク・複数人トークへの参加を許可する** → 有効
   - あいさつメッセージ → 無効、応答メッセージ → 無効（Webhook → 有効）

### 2. Google Apps Script 側

1. https://script.google.com/ → 「新しいプロジェクト」→ `コード.gs` の中身を `gas.gs` の内容で置き換えて保存。
2. 左メニュー「プロジェクトの設定」（歯車）→ 「スクリプト プロパティ」→ プロパティを追加
   - プロパティ: `CHANNEL_ACCESS_TOKEN` ／ 値: 手順1でコピーしたトークン
3. 右上「デプロイ」→「新しいデプロイ」→ 歯車「種類の選択」で **ウェブアプリ**
   - 「次のユーザーとして実行」: **自分**
   - 「アクセスできるユーザー」: **全員**
   - 「デプロイ」→ 初回は権限の承認（外部サービスへの接続・スプレッドシートの作成）
4. 表示された **ウェブアプリのURL（…/exec）** をコピー。

> **ハマりどころ**
> - 「次のユーザーとして実行」を「ウェブアプリケーションにアクセスしているユーザー」にすると、
>   「アクセスできるユーザー」の選択肢から **「全員」が消えます**。先に「自分」にしてから「全員」を選ぶこと。
>   「全員」以外だと匿名アクセスがログイン画面に飛ばされ、ページからの送信もLINEのWebhookも届きません。
> - トークン欄に **Channel secret（32桁）を入れないこと**。必要なのは「チャネルアクセストークン（長期）」（170字程度）です。
>   `…/exec` をブラウザで開いた `tokenSet` は値が空でないかしか見ていないため、誤った値でも `true` になります。
>   確認は `curl -H "Authorization: Bearer <token>" https://api.line.me/v2/bot/info`（誤りなら401）。
> - スクリプトプロパティは実行時に読まれるので、**トークンの差し替えに再デプロイは不要**です。
> - 既存デプロイを鉛筆アイコンで**編集**すればURLは変わりません。「新しいデプロイ」だとURLが変わり、Webhookの再設定が必要です。
> - 種類を選ばずにデプロイすると `…/macros/library/d/…/1` というライブラリURLが出ます。これは使えません。

### 3. Webhook を接続

LINE Developers → チャネル → 「Messaging API設定」→ Webhook URL に手順2のURLを貼り「更新」→
**Webhookの利用** をオン。（「検証」ボタンはGASの仕様で失敗表示になることがありますが動作には影響しません）

### 4. グループに招待

LINEアプリで **「ラクーン　経費報告」** のグループに公式アカウントを招待します。招待すると

> こんにちは、探偵AIが調査のサポートをいたします、よろしくお願いいたします
> （このグループを調査日報の送信先に設定しました）

と返ります。2行目が付いていれば送信先として登録できています。

**日報を送れるのは「ラクーン　経費報告」という名前のグループだけです**（`gas.gs` の `ALLOWED_GROUP_NAME`）。
- 他のグループに招待した場合はあいさつ文だけを返し、送信先は変わりません（地図変換などは普通に使えます）。
- 既にそのグループにいて登録されていない場合は、そのグループで **「日報送信先」** と1行送れば登録されます。
- グループ名は LINE の `GET /v2/bot/group/{groupId}/summary` で確認しています。
  比較のとき **【】・空白・全角半角の違いは無視**するので「【ラクーン　経費報告】」でも一致します。
- 名前を確認できなかったときは送信先を変更しません（誤ったグループに日報が流れるのを防ぐため）。
- 日報の送信直前にも名前を確認します。一致しない場合は送信せず、ページに理由が表示されます。
  グループ名を変えると送れなくなるので、変更したときは `ALLOWED_GROUP_NAME` も直してください。

### 5. ページに URL を設定

`index.html` 冒頭の `const AUTO_SEND_URL` に手順2のURLを入れて GitHub に push します。
ページを開き直すと「LINEグループへの送信」が **自動送信 有効** になり、
画面下の緑のボタンが「LINEグループに送信」になります。

**現在の設定状況**: セットアップ済み（2026-09-07 稼働開始）。
`…/exec` をブラウザで開いて `{"ok":true,"tokenSet":true,"groupSet":true}` が返れば正常です。

## Googleマップのリンクを「名称＋所在地」に変換する（グループ内で自動）

公式アカウントを招待したグループで、**Googleマップのリンクを貼るだけ**で次のように返信します。

```
靖國神社
所在地：東京都千代田区九段北３丁目１−１
```

- **グループにいる誰の投稿でも反応します**（自分だけ・管理者だけという制限はありません）。
  LINEはグループ内のメッセージをすべてWebhookに送るため、メンションも不要です。
  公式アカウントを友だち追加していないメンバーの投稿でも動きます。
- 対応するリンク: `maps.app.goo.gl/…`（スマホの共有）、`goo.gl/maps/…`、
  `google.com/maps/place/…`（PCのアドレスバーの長いURL）、`maps.google.com?q=…`、`g.co/kgs/…`
- **LINEの「位置情報」（＋ → 位置情報 で送るピン）にも対応**しています。URLではなくピンで共有されても、
  そのメッセージに入っている名称・住所を使って同じ形で返します。名称のないピンは所在地の行だけ返します。
- **店名は空白を含んでいてもフルで返します**（例「ほぐし屋 保土ヶ谷店」）。
  地図上で名称が2行に折り返る店は `?q=` 形式のURLだと名称が空白で分かれて入っているため、
  2026-09-08 までは後ろ半分（「保土ヶ谷店」）しか出していませんでした。
- 1通に複数貼っても最大3件まとめて返します。前後に文章が入っていても拾います。
- **地点だけの共有（施設名のないピン）は所在地の行だけ**返します。
- 地図以外のURL・スタンプ・写真には反応しません。
- **返信（応答メッセージ）は無料枠200通/月の対象外**なので、日報の送信数には影響しません。
- 住所は Apps Script の Maps サービスで引いています（APIキー不要・1日1,000件まで）。
  同じリンクは6時間キャッシュするので、貼り直しても件数を消費しません。

> 仕組みのメモ: 短縮URLは本文（HTML）に名称も住所も含んでおらず、302リダイレクト先のURLだけが情報源です。
> そこから施設名と座標（`!3d`/`!4d`）を取り出し、名称＋座標周辺で正引き→座標から逆引きの順で住所を確定しています。
>
> `?q=` 形式は実測でこの並びです（名称は必ず末尾）。
> `〒240-0013 神奈川県横浜市保土ケ谷区帷子町１丁目４４ カサハラビル保土ヶ谷 701号室 ・702号室 ほぐし屋`
> `nameFromQText_` は末尾から左へ、`isAddrPart_`（都道府県始まり・番地・部屋番号・階）に当たるまで
> つなげて名称にします。「〇〇2丁目店」のように数字を含んでも施設名で終わっていれば名称として残します。

### 反映できているかを外から確かめる

`…/exec` をブラウザで開いたときの JSON に **`"version"` と `"mapReply":true`** が入っていれば、
地図変換つきのコードが反映されています。入っていなければ古いバージョンが配られたままです。
同じJSONの **`groupName`（現在の送信先の名前）と `canSend`（日報を送れる状態か）** で送信先の状態も分かります。

リンク単体の変換結果だけを見たいときは（LINEを経由しません）:

```
…/exec?key=nippo&maptest=https://maps.app.goo.gl/xxxxxxxx
```

展開後のURL・取り出した名称と座標・実際の返信文が JSON で返ります。

AI と建物の下調べも、LINEを経由せずに確かめられます（`aitest` と `proptest` はAPI呼び出しを1回消費します）。

```
…/exec?key=nippo&aitest=日報の書き方を教えて          … AIの返答（searches に検索回数が入る）
…/exec?key=nippo&aitest=…&nosearch=1                 … 検索を使わせずに返答
…/exec?key=nippo&proptest=エルザタワー55 埼玉県川口市元郷2丁目   … 建物の下調べ（1〜3分かかる）
…/exec?key=nippo&proptrigger=◯◯マンションを調べて     … 下調べモードと判定されるかだけ見る（無料）
…/exec?key=nippo&memory=1                            … 送信先グループの記憶をそのまま見る（無料）
…/exec?key=nippo&memory=1&gid=<グループID>            … 別のグループを指定して見る
…/exec?key=nippo&memory=1&memnote=1                  … その場で要点メモを書き直す（AI1回ぶん）
…/exec?key=nippo&aitest=…&nomemory=1                 … 記憶を読ませずに答えさせる（比較用）
```

`…/exec` の JSON に **`"webSearch":true`** と **`"groupMemory":true`** が入っていれば、
検索つき・記憶つきのコードが反映されています。
`propCallsToday` / `propDailyLimit` で下調べの残り件数が分かります。

> **コマンドラインから試すときの注意**: Git Bash から `curl.exe` に日本語を直接渡すと
> CP932 に変換されて文字化けします（GAS側は正常）。UTF-8のファイルに書いて
> `--data-urlencode "proptest@q.txt"` の形で渡すか、ブラウザのアドレスバーから開いてください。

### 既存のGASを更新する手順（コマンドで行う場合）

`C:\Users\racoo\gdrive-tools\gas.bat`（Apps Script API のCLI）でコードの差し替えとデプロイができます。

```
gas.bat info                      … ファイル一覧とデプロイ一覧を確認
gas.bat push ..\cd-my-lp\nippo\gas.gs
gas.bat deploy --desc "地図変換"    … 新バージョンを作り既存デプロイを更新（URLは変わらない）
```

初回だけ次の2つが必要です。
1. https://script.google.com/home/usersettings で **「Google Apps Script API」をオン**（アカウント単位の設定）
2. `gas.bat auth`（ブラウザで許可）→ そのあと `gas.bat enable`（GCP側の有効化）

### 既存のGASを更新する手順（手で行う場合）

1. GASエディタで `gas.gs` の内容を**全文貼り替え**（`コード.gs` を全選択して上書き）。
2. エディタ上部の関数選択で **`testMapLink`** を選び「実行」→ 実行ログに変換結果が3件出れば成功です。
   （初回は「承認が必要です」→ 自分のアカウントで許可。外部リクエストの権限が追加されます）
3. **「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新しいバージョン」→「デプロイ」。**
   コードの変更はここで新バージョンを出すまで `…/exec` に反映されません（URLは変わらないのでWebhookの再設定は不要）。

### 他の人の投稿に反応しないときの確認順

1. **新バージョンをデプロイしたか。** 貼り替えただけでは `…/exec` は古いコードのままです（上記手順3）。
2. LINE Official Account Manager → 設定 → **応答設定** で
   **応答モード「Bot」／Webhook「オン」／応答メッセージ「オフ」**（チャットモードだとWebhookに届きません）。
3. LINE Developers → Messaging API設定 → **グループトーク・複数人トークへの参加を許可する** が有効か。
4. それでも無反応なら、GASエディタの「実行数」でWebhookの実行が記録されているか見ます。
   実行が0件ならLINE側の設定、実行はあるがエラーならログに原因が出ます。
   ※ 同じリンクは6時間キャッシュしますが、これは住所の引き直しを省くだけで、返信自体は毎回します。

## 探偵AI（メンションすると考えて返信する）

グループで公式アカウントを **@メンション** すると、Claude（`claude-sonnet-5`）が答えを考えて返信します。

- メンションのほか、**「探偵AI」で始まる発言**でも反応します（端末によってメンション情報が付かないことがあるため）。
- **1:1トークではメンション不要**で、送った発言すべてに答えます。
- 他の人へのメンションや `@all`、ただの雑談には反応しません。
- 同じ発言に地図リンクが入っている場合は、**地図変換を優先**します（AIは呼びません）。
  ただし「@探偵AI この建物を調べて（地図リンク）」のように**建物の下調べを頼んでいるとき**は、
  リンクから名称と所在地を割り出してから調べます（後述）。
- グループごとに会話を**ずっと覚えています**（後述の「グループごとの記憶」）。
- 答えは日本語・結論から先に・目安200〜400字。日報の書き方、経費計算、張り込みや尾行の一般的な段取り、
  報告書の言い回し、探偵業法まわりの一般的な注意などを扱います。
  違法な手段（無断のGPS取り付け、住居侵入、なりすまし、不正アクセスなど）の手順は案内せず、合法的な代替を示します。

### ウェブ検索（2026-09-08 追加）

探偵AIは Claude 側の検索機能（web_search / web_fetch）を使えるので、**ネットで調べたうえで答えます**。

- 使うのは「事実の最新性や裏づけが要るとき」だけです。日報の書き方や経費の単価のような
  社内の運用の話では検索しません（そのぶん速く返ります）。
- 検索して答えたときは、末尾に**出典のサイト名**が付きます。確認できなかったことは
  「確認できなかった」と書き、推測で埋めません。
- **対象者や依頼者など個人をネットで特定する用途には使いません。**
  聞かれた場合は正規の手続き（依頼者からの情報提供、現地調査、公的記録の取得）を案内します。
- 検索した回は返信までに30〜60秒かかることがあります。LINEの返信期限（受信から約60秒）を
  過ぎた場合は自動で push 送信に切り替わるので、答えは必ず届きます。
- **1つの質問で検索するのは最大5回**（`AI_SEARCH_MAX_USES`）、ページの読み込みは最大3回です。
  一度に何県ぶんも聞くなど5回で足りない質問では、**確認できた分を先に答え、残りを「未確認」として挙げます。**
  「検索の上限に達しました」のような内部事情は書かない指示にしてあります（もし出たら教えてください）。
  分けて聞き直せば残りも調べられます。

### グループごとの記憶（2026-09-08 追加）

**グループごとに会話を覚えていて、次に呼ばれたときの前提として使います。** 2階建てです。

| | 中身 | 保存先 | 消えるか |
|---|---|---|---|
| ① 会話ログ | **グループの全発言**（メンションの有無を問わない。スタンプ・写真・位置情報も1行の印として残る） | スプレッドシート「調査日報ログ」の **`グループ会話ログ`** シート | 消えません |
| ② 要点メモ | ①からAIが書き出した要点（案件名・対象・区間・単価・継続中の課題など） | 同じブックの **`グループ記憶`** シート（1グループ1行） | 消えません |

AIが呼ばれると、**②要点メモ＋①の直近20発言**の両方を前提として読みます。
実測では「対象の車は何だったっけ？」に対して、記憶ありなら「シルバーのプリウス（品川ナンバー）」と答え、
記憶なしなら「把握していません」と答えました。

**グループから操作できます**（どちらもAIを呼ばないので無料）。

| 送る言葉 | 動き |
|---|---|
| `記憶` または `メモ` | いま覚えている要点メモをそのまま返す |
| `記憶を消して`（`記憶消して` / `記憶をリセット` / `メモを削除` なども可） | 要点メモを消し、**それ以前の会話ログも読まなくなる**（シート上の記録自体は残る） |

- 要点メモは**8発言たまるごとに書き直され**ます（次にAIが呼ばれたタイミング。返信を送ったあとに実行するので待たされません）。
  久しぶりの呼び出しでも取りこぼさないよう、溜まっていれば最大60発言まで遡って要約します。
- 覚え違いをしていたら、**スプレッドシートの `グループ記憶` シートを直接書き直せます**（AIはそれを読みます）。
- **記録される内容にご注意ください。** グループの全発言が保存対象なので、対象者や依頼者の情報も
  スプレッドシート（ご自身のGoogleアカウント内、`調査日報ログ` と同じブック）に残ります。
  範囲を「AIとやりとりした分だけ」に絞りたい場合は `gas.gs` の `rememberMessage_` の呼び出し位置を
  webhook の先頭から `aiReply_` の中へ移してください。
- 発言者の表示名は LINE の API から取ります（6時間キャッシュ）。取れない場合は「参加者」と記録します。
- 全発言を記録するぶん、1発言ごとにシートへの追記（おおむね1.5〜2秒）が入ります。LINEの返信を待たせる処理ではありません。
- 要点メモの書き直しは1回およそ**0.5〜1円**（`claude-sonnet-5` / effort=low）です。

### 建物（物件）の下調べ（2026-09-08 追加）

**建物名と住所を渡すと、現地調査の前に知りたい項目を調べてまとめます。**

```
@探偵AI 物件調査 エルザタワー55 埼玉県川口市元郷2丁目
```

- 「物件調査」「物件調べ」「建物調査」で始めると専用の書式でまとめます。
  そう書かなくても「〇〇マンション（住所）って単身者向け？」のように
  **建物を指す語＋調べてほしいこと**が入っていれば自動で下調べモードになります。
- 現場で撮った**Googleマップのピンやリンクを一緒に貼ってもOK**です。
  リンクから名称と所在地を割り出してから調べます。
- 返ってくる項目
  - 物件の特定（正式名称／所在地／種別）
  - 規模（**総戸数＝入居可能世帯数**／階数／構造／竣工年）
  - **想定入居層**（単身者中心／単身〜DINKS混在／ファミリー中心）と、その根拠（間取り構成と専有面積）
  - **セキュリティ**（オートロック／防犯カメラ／**コンシェルジュ**・管理人の常駐体制／宅配ボックス／モニター付インターホン）
  - 現地調査メモ（駐車場・駐輪場・出入口・最寄駅・賃料や価格の相場帯）
  - 管理会社・分譲会社
  - **【未確認】**の項目と、その確認方法
- 主に見るサイトは SUUMO、LIFULL HOME'S、アットホーム、マンションレビュー、マンションノート、
  スマイティ、管理会社の公式サイトなどです。
- **出典（参照したサイト名）は本文に書きません**（2026-09-08 変更。（）が多くて読みにくかったため）。
  出典を書かないだけで基準は変わらず、**確認できた値しか書きません**。埋まらない項目は「不明」にして
  【未確認】に回します。サイト間で数値が食い違うときは「1998年3月（サイトにより7月表記あり）」と併記します。
- **防犯カメラの有無は必ず調べます。** 記載が見つかれば「有」、見つからなければ「不明」と書きます
  （「無」と書くのは"無い"と確認できたときだけ）。
- **時間がかかります（おおむね1〜3分）。** 先に「調べています」と返し、
  結果はあとから届く形にしてあります（結果の1通だけ push 扱い）。
- 守っていること
  - 確認できた数値・設備だけ書き、埋まらない項目は「不明」にする（相場や一般論で埋めない）。
  - 住所が一致しない検索結果は使わない。同名物件が複数あって絞れないときは、
    候補の所在地を並べて確認を求める（項目は埋めない）。
  - 不動産サイトの掲載情報は古いことがあるので「掲載時点の情報」と断る。
  - **居住者の氏名・部屋番号・家族構成といった個人の情報は探さないし書かない。** 建物の情報だけを扱う。
- **1日20件の上限**（`PROP_DAILY_LIMIT`）です。超えるとその日は断り、翌日再開します。

### 費用と安全弁

- 料金は Claude API の従量課金（`claude-sonnet-5` は入力 $2 / 出力 $10 per 1Mトークン）。
  1回の返信はおおむね **0.5〜1.5円** です。LINE側の返信は無料枠200通/月の対象外なので、LINEの費用は増えません。
- **1日50回の上限**（`AI_DAILY_LIMIT`）を入れてあります。超えるとその日は断り、翌日再開します。
- **ウェブ検索は検索1,000回あたり $10**（1回およそ1.5円）＋読み込んだ結果のトークン代です。
  通常の会話では検索は0〜5回、**建物の下調べは1件あたりおおむね10〜30円**（検索2〜6回＋結果の読み込み）です。
  下調べは別枠で**1日20件の上限**（`PROP_DAILY_LIMIT`）を入れてあります。
- **`max_uses` は「1リクエストあたり」の上限です。** `pause_turn`（サーバー側ツールの途中）で
  続きを頼むと枠がリセットされるため、素朴に書くと合計が設定値の数倍になります
  （実測: 3回設定で **11回** 走り、1回の会話で約16円かかっていました）。
  `askClaude_` で使った回数を持ち回り、毎回「残り枠」を入れ直して合計を頭打ちにしています。
  枠を使い切ったラウンドでは**ツールを渡さない**ので、そこまでの情報で答えを書きます。
- **調べ物で60秒を超えたときは push 送信に切り替わります**（LINEの返信期限が受信から約60秒のため）。
  push は無料枠 月200通に数えられるので、下調べを多用する月は通数に注意してください。
  速さと費用を調整したい場合は `gas.gs` の `PROP_EFFORT` / `PROP_SEARCH_MAX_USES`（実測: `high`＋10回で196秒、
  `medium`＋6回で44〜63秒）と `AI_SEARCH_MAX_USES` を変えてください。
- より高性能にしたい場合は `gas.gs` の `AI_MODEL` を `claude-opus-5`（入力 $5 / 出力 $25）に、
  じっくり考えさせたい場合は `AI_EFFORT` を `high` に変えてください（そのぶん返信は遅くなります）。
  なお `fallbacks`（断られたときに代替モデルでやり直す指定）は対応モデルが限られるため、
  `claude-opus-5` / `claude-fable-5*` のときだけ自動で付きます。
- 応答が遅いとLINEが同じイベントを再送するため、`message.id` で重複を弾いて二重返信を防いでいます。

## 運用上の注意

- LINE Messaging API の無料枠は **月200通** です。日報1件＝1通（5,000文字以内）です。
  超える見込みなら LINE公式アカウントのプランを上げてください。
- 送信された日報は、GASを作ったGoogleアカウントのドライブに自動作成される
  スプレッドシート「調査日報ログ」にも1行ずつ蓄積されます（送信日時／調査日／案件名／送信者／調査時間／経費合計／本文）。
  同じブックに `グループ会話ログ` と `グループ記憶` の2シートも入ります（探偵AIの記憶）。
  **`SHEET_ID` のスクリプトプロパティが消えると新しい空ブックが作られて過去ログと分断されます。**
  ブックIDは `1RQcZHA37rV-JCVPkV-diWYKWU5OAjjyzR25k0Nf5Ky4` です。
- 自動送信が失敗しても端末内の保存は完了しています。失敗時は共有画面から送るか確認するダイアログが出ます。
  「LINEグループへの送信」欄の「LINEアプリの共有画面から送る（予備）」でも手動送信できます。
- 送信せずに下書きだけ残したいときは、緑のボタンではなく青の「保存」を押してください。
